The **MAP** tab is the plan view of the cave, and where most of the work happens. It has two modes.

| Mode | Purpose |
| --- | --- |
| **Survey (stick) mode** | Work on the survey network itself — select stations, edit shots, add closures, measure distances |
| **[Carto mode](Carto-Mode.md)** | Draw the map — layers, lines, splines, styles, overlays, page setup |

The button on the right edge of the map labelled **CARTO** swaps between them.

## Layout

| Area | Contents |
| --- | --- |
| Centre | The map itself |
| Right panel | The [display panel](Display-Settings.md) in survey mode, the [carto panel](Carto-Mode.md) in carto mode |
| Bottom | The [action pane](Station-Actions.md), shown when two stations are selected |
| Floating | **OPTIONS**, **LOOPS**, **PROJECTS** and **ANNOTATIONS** panels, opened from the display panel |
| Above the map | The [search box](Map-Search.md), zoom controls, snapshot and print buttons |
| Below the map | Cursor coordinates, or the live distance while placing a shot |
