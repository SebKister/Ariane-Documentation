The style bar sets how new elements are drawn, and restyles whatever is currently selected.

| Control | Effect |
| --- | --- |
| **STROKE** | Line colour |
| **THICKNESS** | Line weight |
| **FILL** | Fill colour |
| **OPACITY** | Fill transparency |
| **TYPE** | Line type |
| **PATTERN** | Line pattern |
| **SCALE OF DASHED LINE** | Dash spacing |
| **SCALE OF LINE PATTERN** | Pattern repeat spacing |

## Applying styles broadly

- **SET CURRENT STYLE AS LAYER STYLE** stores these settings on the current [layer](Layers.md);
  ticking **USE LAYER STYLES** then makes every element on that layer follow it.
- **UNICOLOR MODE** overrides all colours with a single chosen colour — useful for producing a
  monochrome map for print.
- **AUTO SIZE THE STROKES THICKNESS** scales line weights with the zoom level, so a drawing keeps its
  visual proportions as you zoom.

:::tip
[Options](Options.md) keeps a separate set of drawing settings for **export**, so the map you look at
on screen and the map you export can have different line weights. Tick **USE DISPLAY SETTINGS** in
Options to export exactly what is on screen instead.
:::
