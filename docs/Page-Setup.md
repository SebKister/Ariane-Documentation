title: Page Setup
sidebar_label: Page setup
---

The **PAGE** section of the carto panel defines the printable sheet the map is laid out on. It
governs both [printing](Map-Output.md) and SVG export.

1. Choose a **paper format** from the list.
2. Choose the orientation.
3. Use the **page adjust** tool from the [tool set](Drawing-Tools.md) to drag and size the page
   rectangle over the drawing until it frames what you want.

The first time you enter [carto mode](Carto-Mode.md) on a project that has no page, Ariane creates a
default page sized to the extent of the survey, so there is always something to adjust rather than
nothing to see.

The page rectangle is drawn on the map as a guide and is not part of the drawing itself.
