Open **PROJECTS** from the [display panel](Display-Settings.md). Ariane remembers every project you
open and lists it here.

## Opening a project

Double-click a project, or select it and press **OPEN SELECTED PROJECT**.

## Background projects

Tick a project to draw it **in the background**, behind the one you are working on. This is how you
check whether a new survey connects to a neighbouring cave, or whether two systems are closer than
anyone thought.

## Geographical areas

The lower tree groups projects by their **geocode** — the `AREA,CITY,STATE,COUNTRY` string set in the
[section description](Section-Description.md) or from [Data Tools](Data-Tools.md). Ticking an area
displays every project in it as background at once.

This is the payoff for filling in the geocode: *"show me everything surveyed in this area"* becomes
a single click.

## Housekeeping

| Control | Effect |
| --- | --- |
| **REMOVE SELECTED PROJECT FROM LIBRARY** | Forgets a project. The file itself is not deleted |
| **SHOW AT STARTUP** | Opens the library automatically when Ariane starts |
| **DISPLAY SELECTION** | Restricts the background display to the current selection |
