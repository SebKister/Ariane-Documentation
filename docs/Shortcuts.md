## 2D map — survey mode

| Input | Action |
| --- | --- |
| Wheel | Zoom |
| Drag background | Pan |
| **Ctrl** + drag | Pan regardless of the active tool |
| Click station | Select as first, then as second, station |
| **Ctrl** + click station | Add to the multi-selection |

## 2D map — carto mode

| Input | Action |
| --- | --- |
| Drag | Use the active tool |
| **Ctrl** + drag | Pan |
| **Escape** | Clear the selection |
| **Delete** / **Backspace** | Erase the selected elements |
| **Ctrl+X** | Cut |
| **Ctrl+C** | Copy |
| **Ctrl+V** | Paste |
| **Shift** + click a spline | Add a control point |
| **Ctrl** + click a spline | Cut the spline at that point |
| **Shift** + click a grip | Remove that control point |

## 3D view

| Input | Action |
| --- | --- |
| Left drag | Orbit |
| Right drag | Move / dolly |
| Wheel | Zoom |
| Left click station | Centre the camera on it |
| Right click station | Show its ID |
| Hold **Ctrl** | Show stations, hide filled walls |
| Right click LIDAR point | Remove that LIDAR record |

## Tables in Excel sheet mode

| Key | Action |
| --- | --- |
| **F2** | Edit the focused cell |
| Any character | Start editing, replacing the content |
| **Enter** / **Shift+Enter** | Move down / up |
| **Tab** / **Shift+Tab** | Move right / left |
| **Delete** / **Backspace** | Clear the cell |

## Complex profile editor

| Key | Action |
| --- | --- |
| **Delete** / **Backspace** | Remove the selected radius vector |

## Window

| Input | Action |
| --- | --- |
| Drag the header | Move the window |
| Double-click the header | Maximise / restore |
| Drag the bottom-right grip | Resize |
