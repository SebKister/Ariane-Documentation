## Statistics

The **STATISTICS** tab computes on demand — press **UPDATE**.

The general panel lists:

| Figure | |
| --- | --- |
| **Stations** | Number of stations |
| **Sections** | Number of sections |
| **Entries** | Number of entrances |
| **Loops/Connections** | Number of closures |
| **Length** | Total surveyed length |
| **Average shot length** | Mean length of a shot |
| **Maximum Depth** | Deepest point |
| **Average Depth** | Mean depth |
| **EOLs** | Number of end-of-line points |
| **Volume** | Computed passage volume |

Charts show cumulative length over time, entry counts, station counts, a station scatter plot, and
the **SURVEYOR LEADERBOARD** and **EXPLORER LEADERBOARD** rankings.

**PRINT** prints the page.

:::note
Statistics are computed from the *visible* data. Anything hidden by a
[Data Table filter](Data-Table.md), or marked excluded, is left out.
:::

## Report

The **REPORT** tab is a printable text summary of the same figures, plus:

- **EOL Maximum Remoteness** — the furthest end-of-line from the entrance
- The full lists of **surveyors** and **explorers**

**UPDATE** rebuilds it and **PRINT** prints it. The report can also be exported as
[HTML](Import-Export.md) from the toolbar's export menu.
