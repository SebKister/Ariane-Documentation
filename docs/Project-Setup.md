The top panel of the [Data Wizard](Data-Wizard.md) defines the project itself.

1. Type a **project name**.
2. Choose the **unit**: `Meter` or `Feet`.
3. Press **APPLY**.

Nothing else in the wizard will work until this is done — Ariane refuses with
*"Name or unit have not been defined for the project"* otherwise.

The project name and unit are shown in the application header once applied, and the panel collapses
so you can move on to the [start point](Start-Point.md).

:::note
The unit applies to the whole project: shot lengths, depths, LRUD dimensions and every computed
statistic. To change it later, use *PROJECT → CHANGE UNIT* in [Data Tools](Data-Tools.md), and note
that this changes the declared unit — use the [conversion buttons](Unit-Conversions.md) if the
numbers themselves need converting.
:::
