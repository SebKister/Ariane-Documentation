Drawing is organised into **layers**, so passage outline, floor detail and symbols can be managed —
and shown or hidden — independently.

| Control | Effect |
| --- | --- |
| **ADD NEW LAYER** | Creates a layer |
| **Delete** | Removes the selected layer |
| **Up** / **Down** | Reorders layers, which sets what draws on top |
| Visibility toggle | Shows or hides a layer |

One layer is always the **current** layer. New elements are drawn into it, and deleting a selection
removes elements from it.

## Layer styles

| Control | Effect |
| --- | --- |
| **SET CURRENT STYLE AS LAYER STYLE** | Stores the current [style bar](Styles.md) settings on the layer |
| **USE LAYER STYLES** | Makes elements draw with their layer's style instead of their own |

This is how you restyle a whole class of features at once: set the layer style, tick **USE LAYER
STYLES**, and every element on that layer follows.
