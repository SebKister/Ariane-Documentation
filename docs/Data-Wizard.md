The **DATA WIZARD** tab is where survey data enters Ariane. Click **START A NEW PROJECT** in the
toolbar, then work down the wizard's panels in order. Each panel collapses when it is satisfied and
opens the next one.

## The five steps

1. **[Project name and unit](Project-Setup.md)** — name the project and choose metres or feet.
2. **[Start of the new section](Start-Point.md)** — anchor the section to GPS coordinates or to an
   existing station.
3. **[Description of the new section](Section-Description.md)** — name, date, surveyor, explorer and
   optional geocoding.
4. **[Entering the data](Entering-Data.md)** — one row per shot, or
   [downloaded from a device](Device-Import.md).
5. **ADD SECTION** — commit the section to the project.

## Committing a section

**ADD SECTION** validates the data and asks for confirmation before adding it. If a section with the
same name already exists, Ariane offers to *push* the new shots into it instead of creating a
duplicate. On success you get a confirmation that the section was added.

**RESET** clears the wizard and starts a fresh section. Ariane asks before discarding what you have
typed.

:::tip
The wizard is not the only way to edit data. Once a section exists you can correct it in the
[Data Table](Data-Table.md), in the action pane at the bottom of the [map](Station-Actions.md), or
in bulk from [Data Tools](Data-Tools.md).
:::
