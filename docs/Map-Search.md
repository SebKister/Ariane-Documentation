---
title: Searching the Map
sidebar_label: Search
---

The search box above the map finds stations by text.

Type a value and press **SEARCH**. Ariane matches the text, case-insensitively, against essentially
every field of every station:

- `Name`, `Comment`, `Color`, `Date`, `Explorer`, `Section`, `Type`, profile type
- `ID`, `FromID`, `ClosureToID`
- `Length`, `Azimut`, `Inclination`, `Depth`
- `Left`, `Right`, `Up`, `Down`
- `Latitude`, `Longitude`

Every station that matches is selected and highlighted on the map at once — so searching for a
section name lights up the whole section, and searching for a depth value lights up every station at
that depth.

**CLEAR SEARCH RESULTS** clears the selection.

:::tip
To *filter* the data rather than merely highlight it — hiding everything else from the map,
statistics and exports — use the filters in the [Data Table](Data-Table.md) instead.
:::
