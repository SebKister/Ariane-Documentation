| Action | How |
| --- | --- |
| Zoom | Mouse wheel, the **ZOOM IN** / **ZOOM OUT** buttons, or the zoom slider |
| Pan | Drag the map background |
| Pan while a tool is active | Hold **Ctrl** and drag — the cursor becomes a hand |
| Centre the survey in the view | **CENTER VIEW** |

Zooming is animated, so a large jump settles smoothly rather than snapping.

## Readouts

The bar under the map shows the **latitude and longitude** under the cursor, in decimal degrees.

While a first station is selected and you are moving towards the second, the same readout switches to
the live **distance** from the selected station instead, and a curve follows the cursor.

A **scale bar** can be shown on the map itself — toggle **SCALE** in the
[display panel](Display-Settings.md).

## Large projects

If panning and zooming feel heavy on a big system, turn on **BIG DATA MODE** in the display panel or
[Options](Options.md). Ariane then draws only part of the data when you zoom out, which keeps the map
both readable and responsive. See [Troubleshooting](Troubleshooting.md) for the full list of
performance levers.
