Press the **CARTO** button on the right edge of the [map](Map-Overview.md) to switch from survey mode
into drawing mode. The display panel is replaced by the carto panel, and the drawn elements become
clickable.

Carto mode is where the survey becomes a *map*: passage outlines, floor detail, symbols and
annotations drawn over the survey network, organised into layers and laid out on a printable page.

## Panning while drawing

Holding **Ctrl** temporarily switches to the hand cursor, so you can pan without putting the active
tool down. Releasing **Ctrl** restores the tool.

## Global carto options

| Option | Effect |
| --- | --- |
| **AUTO SIZE THE STROKES THICKNESS** | Scales line weights with the zoom, so the drawing keeps its proportions |
| **UNICOLOR MODE** | Draws every element in one chosen colour |
| **SHOW CONSTRAINTS** | Shows or hides constraint geometry |
| **MAGNET** | Snaps new geometry to nearby elements |
| **GRIP** / **CONTROL SIZE** | How large the editing handles are drawn |
| **Create Wall** | Builds wall geometry from the survey |

The first time you enter carto mode on a project with no page defined, Ariane creates a default page
sized to fit the survey.
