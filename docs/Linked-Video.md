A video file can be attached to a survey so that playback and position stay in step — useful for
reviewing cave-diving footage against the line.

Supported formats: **AVI** and **MP4**.

## Creating links

A link ties one playback **time** to one **station**.

| Button | Effect |
| --- | --- |
| **ADD** | Creates a link at the current playback position and selected station |
| **REMOVE** | Deletes the selected link |
| **SAVE** | Writes the link file |

**Link edit mode** lets you place new links while the video plays, which is the fastest way to
annotate a long dive: play, and click at each recognisable station.

## Playback controls

The transport controls in the application header:

| Control | Effect |
| --- | --- |
| **PLAY / PAUSE** | Start or stop playback |
| Previous / next station | Jump to the previous or next linked station |
| Sound on/off | Mute |
| **HIDE** | Hides the video pane |

As the video plays, the corresponding position is followed on the map.

## Placement

The video pane can be docked in either the [2D map](Map-Overview.md) or the [3D view](Map-3D.md).

Linked videos attached to [aggregation](Aggregator.md) members are re-associated with their stations
when the aggregated display is built.
